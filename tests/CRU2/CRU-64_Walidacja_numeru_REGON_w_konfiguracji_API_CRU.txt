ID: CRU-64
Moduł: CRU
Typ: Walidacyjny
Priorytet: krytyczny/natychmiastowy
Poziom: Zaawansowany

<h1> Walidacja numeru REGON w konfiguracji API CRU </h1>

<h2> Cel testu </h2>

Celem testu jest sprawdzenie scenariusza: Walidacja numeru REGON w konfiguracji API CRU.

<h2> Rozdział dokumentacji </h2>

Konfiguracja CRU API — token per stanowisko, konfiguracje aktywne/nieaktywne oraz wybór konfiguracji dla umowy

<h2> Warunki wstępne </h2>

- System EZD jest uruchomiony i dostępny.
- Użytkownik jest zalogowany do systemu EZD.
- Użytkownik posiada uprawnienia do Administracja → Ustawienia Ogólne → Rozszerzenia → Ustawienia rozszerzeń → CRU.

<h2> Kroki testowe </h2>

| Krok | Czynność | Oczekiwany rezultat |
|---:|---|---|
| 1 | Otwórz formularz nowej konfiguracji CRU API i uzupełnij poprawnie pozostałe pola. | Formularz jest gotowy do testu pola Regon. |
| 2 | Wprowadź wartość krótszą niż 9 znaków i spróbuj zapisać. | System odrzuca wartość Regon. |
| 3 | Wprowadź wartość dłuższą niż 14 znaków i spróbuj zapisać. | System odrzuca wartość Regon. |
| 4 | Wprowadź znaki inne niż cyfry i spróbuj zapisać. | System odrzuca wartość Regon. |
| 5 | Wprowadź liczbową wartość o poprawnej długości, ale niespełniającą walidacji REGON. | System odrzuca niepoprawny REGON. |
| 6 | Wprowadź poprawny REGON i zapisz. | Konfiguracja zostaje utworzona. |

<h2> Kryteria akceptacji </h2>

- Wszystkie kroki testowe kończą się rezultatem zgodnym z oczekiwaniem.
- Stan konfiguracji lub przypisania pozostaje zgodny po odświeżeniu widoku.
- System nie udostępnia konfiguracji CRU poza zakresem wynikającym z jej statusu oraz przypisania do użytkownika i stanowiska.
