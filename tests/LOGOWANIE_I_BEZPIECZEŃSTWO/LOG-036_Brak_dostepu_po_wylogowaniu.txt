ID: LOG-036
Moduł: LOGOWANIE I BEZPIECZEŃSTWO
Typ: Bezpieczeństwo / Dobra praktyka
Priorytet: Krytyczny
Poziom: Zaawansowany

<h2> Cel testu </h2>

Weryfikacja braku dostępu do chronionego widoku po prawidłowym wylogowaniu użytkownika.

<h2> Rozdział dokumentacji </h2>

Test jakościowy poza bezpośrednim zakresem instrukcji; powiązany z funkcją wylogowania

<h2> Warunki wstępne </h2>

- Użytkownik jest zalogowany.
- Otwarty jest chroniony widok zawierający dane dostępne wyłącznie po zalogowaniu.
- Zapamiętano adres URL tego widoku.
- Test jest świadomie oznaczony jako dobra praktyka bezpieczeństwa, a nie literalne wymaganie instrukcji.

<h2> Kryteria akceptacji </h2>

- Po wylogowaniu chroniony widok nie jest dostępny.
- Użycie przycisku Wstecz nie przywraca aktywnego dostępu do danych.
- Bezpośrednie użycie zapamiętanego adresu wymaga ponownego uwierzytelnienia.
- Nie jest tworzona nowa sesja bez podania danych logowania.

<h2> Kroki testowe </h2>

| Krok | Czynność | Oczekiwany rezultat |
|---:|---|---|
| 1 | Zapamiętać adres URL chronionego widoku. | Adres widoku jest dostępny do dalszego testu. |
| 2 | Wylogować użytkownika funkcją „WYLOGUJ SIĘ” / „Wyloguj”. | Sesja użytkownika zostaje zakończona. |
| 3 | Użyć przycisku Wstecz przeglądarki. | System nie przywraca aktywnego dostępu do chronionych funkcji. |
| 4 | Wprowadzić bezpośrednio zapamiętany adres URL. | System wymaga ponownego zalogowania lub odmawia dostępu. |
| 5 | Zweryfikować brak dostępu do danych chronionego widoku. | Dane nie są dostępne bez ponownego uwierzytelnienia. |
