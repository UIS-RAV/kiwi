<h1> Dezaktywacja konfiguracji CRU API </h1>

<h2> Cel testu </h2>

Celem testu jest sprawdzenie scenariusza: Dezaktywacja konfiguracji CRU API.

<h2> Rozdział dokumentacji </h2>

Konfiguracja CRU API — token per stanowisko, konfiguracje aktywne/nieaktywne oraz wybór konfiguracji dla umowy

<h2> Warunki wstępne </h2>

- System EZD jest uruchomiony i dostępny.
- Użytkownik jest zalogowany do systemu EZD.
- Użytkownik posiada uprawnienia do Administracja → Ustawienia Ogólne → Rozszerzenia → Ustawienia rozszerzeń → CRU.
- Istnieje aktywna konfiguracja CRU API, dla której funkcja Dezaktywuj jest dostępna.

<h2> Kroki testowe </h2>

| Krok | Czynność | Oczekiwany rezultat |
|---:|---|---|
| 1 | W zakładce „Aktywne” wybierz „Dezaktywuj”. | System wyświetla modal z pytaniem „Czy dezaktywować konfigurację CRU?” oraz informacją, że konfiguracja przestanie być dostępna do użycia. |
| 2 | Wybierz „Dezaktywuj” w modalu. | System zmienia status konfiguracji na nieaktywną, zamyka modal i odświeża ekran. |
| 3 | Otwórz zakładkę „Nieaktywne”. | Dezaktywowana konfiguracja jest widoczna na liście. |

<h2> Kryteria akceptacji </h2>

- Wszystkie kroki testowe kończą się rezultatem zgodnym z oczekiwaniem.
- Stan konfiguracji lub przypisania pozostaje zgodny po odświeżeniu widoku.
- System nie udostępnia konfiguracji CRU poza zakresem wynikającym z jej statusu oraz przypisania do użytkownika i stanowiska.
