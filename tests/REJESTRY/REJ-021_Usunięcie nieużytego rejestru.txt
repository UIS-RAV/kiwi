<h1> Usunięcie nieużytego rejestru </h1>

<h2> Cel testu </h2>

Zweryfikowanie usunięcia rejestru, który nie został użyty.

<h2> Rozdział dokumentacji </h2>

Rejestry definiowane - konfiguracja / Usunięcie rejestru

<h2> Warunki wstępne </h2>

- Istnieje rejestr bez wpisów.

<h2> Kroki testowe </h2>

| Krok | Czynność | Oczekiwany rezultat |
|---:|---|---|
| 1 | Otwórz listę rejestrów. | Lista jest widoczna. |
| 2 | Otwórz menu opcji przy nieużytym rejestrze. | Dostępna jest akcja Usuń rejestr. |
| 3 | Kliknij Usuń rejestr. | System żąda potwierdzenia. |
| 4 | Potwierdź usunięcie. | System wykonuje operację. |
| 5 | Odśwież listę. | Rejestr nie jest widoczny. |
| 6 | Sprawdź boczne menu Rejestry. | Usunięty rejestr nie jest dostępny użytkownikowi. |
| 7 | Odśwież listę rejestrów i ponownie wyszukaj testowany rejestr. | Rejestr pozostaje widoczny w stanie zgodnym z wykonaną operacją. |
| 8 | Otwórz konfigurację rejestru albo jego podgląd, jeżeli operacja jest dostępna. | Przypisana numeracja, szablon, aktywność i dostępne akcje są spójne z konfiguracją. |

<h2> Kryteria akceptacji </h2>

- Rejestr zostaje usunięty.
- Wszystkie kroki testowe kończą się rezultatem zgodnym z oczekiwaniem.
- Stan numeracji, szablonu, rejestru lub wpisu pozostaje spójny po odświeżeniu i ponownym odczycie.
- Dostępne operacje odpowiadają stanowi użycia elementu i nie naruszają integralności konfiguracji.
