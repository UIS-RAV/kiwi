<h1> Import odwzorowań do EZD </h1>

<h2> Cel testu </h2>

Zweryfikowanie, że funkcja „Import odwzorowań do EZD” realizuje opisany proces poprawnie, zachowuje spójność danych dokumentu i daje trwały rezultat możliwy do potwierdzenia w DKP, podglądzie lub historii.

<h2> Rozdział dokumentacji </h2>

Import odwzorowań do EZD

<h2> Warunki wstępne </h2>

- Użytkownik jest zalogowany do systemu EZD.
- Użytkownik posiada uprawnienia wymagane do wykonania operacji.
- Przygotowano dane, dokumenty lub pliki odpowiadające scenariuszowi testowemu.

<h2> Kryteria akceptacji </h2>

- Funkcja „Import odwzorowań do EZD” jest dostępna dla uprawnionego użytkownika i kończy się zgodnie z celem testu.
- Dane dokumentu, interesantów, załączników lub dekretacji odpowiadają wykonanej operacji.
- Rezultat jest widoczny we właściwym widoku i pozostaje spójny po ponownym otwarciu danych.
- Operacja nie powoduje niezamierzonych zmian w innych dokumentach ani rekordach.

<h2> Kroki testowe </h2>

| Krok | Czynność | Oczekiwany rezultat |
|---:|---|---|
| 1 | Przygotuj zakończoną partię odwzorowań zgodną z konfiguracją skanowania wsadowego. | Pliki i metadane są gotowe do importu. |
| 2 | Uruchom import odwzorowań do EZD. | System rozpoczyna przetwarzanie partii. |
| 3 | Poczekaj na zakończenie importu i sprawdź wynik. | System prezentuje liczbę zaimportowanych elementów oraz ewentualne błędy. |
| 4 | Otwórz zaimportowane dokumenty lub odwzorowania. | Pliki są dostępne przy właściwych rekordach i w prawidłowej kolejności. |
| 5 | Porównaj dane z partią źródłową. | Import jest kompletny i nie zawiera obcych ani zduplikowanych elementów. |
