<h1> Rejestracja aplikacji Microsoft 365 dla integracji z EZD </h1>

<h2> Cel testu </h2>

Zweryfikowanie, że funkcja „Rejestracja aplikacji Microsoft 365 dla integracji z EZD” działa zgodnie z opisanym procesem oraz prawidłowo obsługuje konfigurację skrzynki, wiadomości, załączniki, synchronizację, przypisania i operacje dostępne w module Poczta e-mail.

<h2> Rozdział dokumentacji </h2>

Moduł poczta / E-mail - konfiguracja / Konfigurowanie poczty Microsoft 365 do pracy z EZD

<h2> Warunki wstępne </h2>

- Użytkownik posiada dostęp administracyjny do właściwego katalogu Microsoft Azure.

<h2> Kroki testowe </h2>

| Krok | Czynność | Oczekiwany rezultat |
|---:|---|---|
| 1 | Zaloguj się do Azure i otwórz Azure Active Directory → Rejestracje aplikacji. | Wyświetla się lista zarejestrowanych aplikacji. |
| 2 | Jeżeli aplikacja nie istnieje, wybierz „Nowa rejestracja”, podaj nazwę i wybierz konta tylko w katalogu organizacyjnym. | Aplikacja zostaje przygotowana do rejestracji. |
| 3 | Wybierz „Rejestruj”. | Aplikacja zostaje utworzona i można przejść do jej konfiguracji. |
| 4 | Odśwież widok lub otwórz dane ponownie. | Rezultat pozostaje spójny po ponownym odczycie. |
| 5 | Sprawdź, czy operacja nie zmieniła danych nieobjętych scenariuszem. | Pozostałe dane skrzynki i wiadomości pozostają niezmienione. |

<h2> Kryteria akceptacji </h2>

- Funkcja „Rejestracja aplikacji Microsoft 365 dla integracji z EZD” kończy się rezultatem zgodnym z celem testu.
- Dane skrzynki, wiadomości, przypisania, załączniki i statusy są zapisane lub prezentowane zgodnie ze scenariuszem.
- Rezultat jest spójny pomiędzy listą wiadomości, podglądem, konfiguracją i powiązanym dokumentem EZD.
- Stan końcowy pozostaje zachowany po odświeżeniu widoku lub ponownym otwarciu danych.
