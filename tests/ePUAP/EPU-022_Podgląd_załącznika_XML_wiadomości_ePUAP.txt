<h1> Podgląd załącznika XML wiadomości ePUAP </h1>

<h2> Cel testu </h2>

Weryfikacja otwarcia dokumentu XML dołączonego do wiadomości.

<h2> Rozdział dokumentacji </h2>

ePUAP / ePUAP - użytkowanie / Podgląd załącznika XML dołączonego do wiadomości ePUAP

<h2> Warunki wstępne </h2>

- System EZD jest uruchomiony i dostępny.
- Użytkownik jest zalogowany do systemu EZD.
- Użytkownik posiada dostęp do modułu ePUAP.
- Połączenie i skrytka ePUAP są poprawnie skonfigurowane oraz mają pozytywny wynik testu.
- Istnieje wiadomość ePUAP zawierająca załącznik XML.

<h2> Kryteria akceptacji </h2>

- Załącznik XML można otworzyć i zweryfikować.

<h2> Kroki testowe </h2>

| Krok | Czynność | Oczekiwany rezultat |
|---:|---|---|
| 1 | Otwórz podgląd wiadomości ePUAP. | Wyświetlają się szczegóły wiadomości. |
| 2 | Wybierz załącznik XML. | System otwiera podgląd lub udostępnia zawartość XML. |
| 3 | Zweryfikuj zawartość. | Załącznik odpowiada plikowi otrzymanemu przez ePUAP. |
